## 字段计算方式

- 本卡块数上限=floor(启动profile的可用KV预算字节数 / 每block物理跨度)。
- P实际分配块数取各PP本卡上限最小值；D独立计算。
- KV物理池=实际块数×每block字节数/1024³；共享底层物理存储只计一次。
- 未利用KV预算=启动预算−物理池，不是池内空闲块，也不是整卡空闲显存。
- 主模型与DSpark权重按GPU参数存储去重统计；DSpark列扣除与主模型共享的存储。
- 其他约=GPU快照已用−两类权重−KV物理池。所有计算使用未舍入数值。
- D行内部审计来自DP0代表副本；四张D卡各自的NVML快照保存在summary.json的d_gpu_snapshots及原始CSV。
- 整卡空闲直接取GPU快照；驱动预留显存可能使已用加空闲小于标称总显存，不能强行补差。
- 每1M请求所需块数为全长组块数加各SWA组窗口/在途块数；容量=floor((实际块数−1个空块)/每请求块数)。
- 1M容量是实际布局计算上限，不是1M长请求压测；仅验证短请求、真实PD外部KV传输及完整生成链路。

## 当前训练复盘与下一阶段建议

复盘快照：训练step4420，完成2.111个epoch；最近100step平均5.91秒/step。现有训练没有被本任务停止或修改。

**最佳已完成评测为step800，接受长度3.8885。**后期没有稳定超过该点，不能用最新step代替最佳模型。

- 当前仅训练最后一层attention的6个张量，其余MLP、前四层及Markov均冻结；主要监督来自旧GQA草稿教师，而不是实际MG43主模型。
- 当前loss已经包含KL + 0.5 prefix-overlap + 0.02 attention NMSE，并不是没有prefix项。新方案的关键是改变监督对象、训练范围和温度对齐，不是把原有prefix项换个名字。
- 训练窗口均值显示KL和总loss仍在下降，同批次探针多数改善；这证明局部拟合有效，不等于真实引擎接受长度持续提高。
- 固定300条请求中188条temperature=0.6，23条为greedy；当前蒸馏loss固定T=1。该差异是已确认的目标对齐问题，但不是已证明的唯一根因。
- 当前0831数据约占训练样本11.6%，codearts和zhouhong合计约59%；这不等于以0831为主的目标配方。
- 当前固定0831诊断与蒸馏数据有重叠，不能把它称为完全未见验证集。

### 推荐：5SWA的主模型监督SFT，而非继续单层模仿蒸馏

1. **直接复用65,284条已配对数据**：其投影SHA与当前GQA一致，保存了同一次前向的归一化最终HS，可用已保存MG43 lm_head恢复目标分布，不需重新生成response或运行主模型。新检查覆盖全部manifest元信息及27份抽样文件header，不声称新做了全量文件哈希审计。
2. **开放五层attention、MLP、norm及低学习率Markov**；冻结fc、hidden_norm、embedding、lm_head和confidence，继续保留5SWA2048架构，不增加推理KV。
3. **改为真实MG43分布的prefix/WTV目标，加0.1 forward KL稳定项**；去掉对全注意力草稿教师的attention NMSE。按实际温度/处理器对齐，greedy单独使用平滑top-1前缀目标；不把代理loss称为实际接受长度。
4. 配方采用0831/现网/其他=40%/30%/30%的目标loss权重，保留每条合格数据每epoch一次；新阶段计划3epochs，重置优化器，分组低学习率，避免只增加旧蒸馏epoch。
5. **只读取原始投影的SWA所需切片**，保留绝对RoPE位置，不重新计算截断主模型HS。按manifest，context有效载荷由30.70TiB降至不超过2.61TiB；这是载荷估算，不是实测训练加速倍率。CPU索引/掩码测试通过，真正启动前仍需GPU前向/梯度等价检查。
6. 继续独立0831-300引擎评测，保持原standard验证口径；增加固定样本/固定anchor主模型loss，区分batch难度、目标拟合和真实接受长度。

上述方案**仅设计、尚未启动**，没有为此打断现有训练。详细超参数和启动前校验见proposed-training-plan.json。不能保证一定超过某个接受长度。
温度与接受目标对齐的依据：[Acceptance-Aware Draft Model Training](https://arxiv.org/html/2609.24150v1)。本方案对当前DSpark的适配仍需验证，并不宣称完全复现论文。
**目标边界：以上配对HS来自MG43，而本次显存实验主模型是NVFP4-nvidia。**若后续训练目标改为NVIDIA版本，须使用该目标同一次前向的配对数据，不能拼接MG43投影与NVIDIA最终HS。
